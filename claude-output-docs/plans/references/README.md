# references/

Durable reference playbooks distilled from research and build experience — patterns and external
citations, not project state. Each doc carries the doc-kit frontmatter contract and a 365-day TTL.

This is a PUBLIC repo: only **sanitized, rewritten-from-scratch** material lands here. No work-org,
employer, or client identifiers; prior art from other contexts is referenced abstractly. A
commit-time token scan enforces this — it is a backstop, not the rule.
