# claude-output-docs/

Artifact store for Claude work products.

| Subdir | Holds |
|---|---|
| `plans/` | Design & build plans (incl. `os-design/` for the labOS plan) |
| `research/` | Research outputs |
| `history/` | Completed-work log |

Each artifact carries frontmatter + a status taxonomy (DRAFT / IN-FLIGHT / DONE / ARCHIVED).
